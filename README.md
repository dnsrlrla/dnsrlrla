## 1️⃣ 🎫 클리어티켓 (ClearTicket)

> **공연 예매가 어려운 입문자를 위해 복잡한 탐색을 줄여주는 AI 맞춤형 공연 추천 & 예매 플랫폼**

[![GitHub](https://img.shields.io/badge/GitHub-ClearTicket-181717?style=flat-square&logo=github)](https://github.com/ClearTiket/ClearTiket)

### 📌 프로젝트 개요
* **수행 기간**: 2026.06 ~ 2026.07 (2개월)
* **수행 인원**: 3명
* **기획 배경**: 공연 예매가 생소하거나 취향에 맞는 공연을 선택하기 힘들어하는 사용자를 위해 진입장벽을 낮추고 탐색 과정을 단축하는 플랫폼을 기획했습니다.
* **프로젝트 목표**:
  * Spring Boot 기반 풀스택 백엔드 개발 역량 내실화
  * Python을 활용한 공공 데이터 수집 및 전처리 파이프라인 자동화
  * AI 임베딩 모델과 Elasticsearch를 결합한 개인화 추천 엔진 구현

### 👤 담당 역할 및 주요 성과
* **자동화 데이터 수집 파이프라인 구축**
  * `Python requests`로 KOPIS(공연예술통합전산망) API 데이터 수집
  * `Pandas`로 DB 스키마에 맞게 전처리 후 `Psycopg` 연동을 통한 PostgreSQL 적재 원스톱 파이프라인 구축
* **Elasticsearch 기반 검색 시스템 개발**
  * DB 데이터를 인덱싱하여 `Bool`, `Must`, `Should` 쿼리 기반 정교한 태그 필터링 검색 구현
* **AI 임베딩 모델 활용 추천 엔진 개발**
  * `ko-SRoBERTa` 모델 기반 태그 임베딩 및 코사인 유사도(Cosine Similarity) 계산으로 자동 태그 할당
  * Elasticsearch 가중치 검색(Weight Search)을 적용해 사용자 선호 태그 중심의 맞춤 공연 탐색 기능 구현
